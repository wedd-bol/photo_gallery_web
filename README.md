# Light Index / 光的索引

基于四张参考截图重做的摄影档案 demo：动态视频首页 → 一次性图形闪烁转场 → 可展开的胶片档案 → 纵向日记 → 背景虚化的照片详情。使用 React + Tailwind CSS + Framer Motion，本地打包，无 CDN 或外部字体依赖。

## 本地运行

Node.js 20 或更高版本：

Windows 可直接双击仓库根目录的 **`start-preview.cmd`**，然后访问 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。它直接运行已交付的页面，不安装依赖；浏览期间请保留打开的终端窗口。若重启电脑或关闭服务后链接无法访问，再次双击该文件即可恢复。

需要修改源码并自动重新构建时，使用开发模式：

```powershell
npm run dev
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。开发模式监听 JSX、内容配置和 Tailwind，修改后刷新浏览器。自定义端口可先设置 `$env:PORT = '4174'`。

```powershell
npm run build
npm start
```

编译结果随项目交付于 `assets/app.js` 和 `assets/tailwind.css`。`npm start` / `node server.mjs` 可直接预览已有构建。服务器只监听本机，并支持 MP4 的字节范围请求。预览期间需要保持服务进程运行；本次交付会保留已启动的预览服务。

## 四个画面的操作

1. **首页**：真实的本地雪山徒步视频，静音自动播放。向下滚轮、上滑、按 ↓ / PageDown，或点击横幅 / 入口箭头，会触发一次胶片转场。右上角 daybook 可直接查看林间日记。
2. **FILM ARCHIVE**：五张纵向照片卡。整页均可上下滚轮浏览，悬停或方向键也可切换；点击打开对应日记。卡片宽度、明暗与下方指示点共用一条阻尼曲线，标题交叉淡入。没有自动轮播。
3. **DAYBOOK**：沿中轴排列的三张影像，左侧短文、右侧帧索引。桌面滚轮平滑跟随，反向滚动立即响应；点击照片展开详情，左上角返回档案。
4. **详情**：保留背后的日记并虚化背景，左侧文字卡、右侧完整照片。支持前后篇、方向键、Esc、关闭按钮和浏览器返回。关闭恢复阅读位置和触发焦点。

小屏会调整视频窗口、卡片和详情为可触摸的布局。系统减少动态设置会即时停止视频自动播放，并将闪烁替换成短黑场。

## 滚轮与阅读节奏

- 档案统一处理像素、行、页三种滚轮单位。一次触控板滑动的衰减尾段不会连续跳过多个系列；持续拨动鼠标滚轮仍可连续浏览，反向操作无需等固定锁定时间。
- 卡片展开采用无回弹的临界阻尼，重新输入时从当前宽度和速度继续；指示点始终跟随实际展开位置。滚轮期间，卡片移动到静止鼠标下方不会抢回选中项。
- 日记页仅对桌面精细指针的纵向滚轮作轻量缓动，始终使用真实文档滚动。键盘、拖动滚动条、点击、切到后台或打开详情都会停止剩余惯性。
- 手机触摸保持原生惯性；减少动态模式使用原生文档滚动及即时卡片切换。无视差、自动滚动或持续运行的动画循环。

## 胶片闪烁转场

- 总时长 **3200ms**，一次触发后锁定重复输入；浏览器返回可取消尚未完成的转场和定时跳转。
- 开场对位框建立节奏，再进入 **03 / 02 / 01** 计数。保留矢量对位标记，增加环形刻度、数字残影、灰阶密度片和胶片边缘跳动。
- RECALL / MEMORY / ARCHIVE 三段巨幅文字交错切片，MEMORY 阶段叠加十二格抽象网格，最后由双向快门打开档案。
- 转场不读取 `photos.js`，没有照片、视频、图片 URL 或相册素材预加载；即使全部照片留空也可正常播放。
- 曝光亮起在约 608ms、1376ms、2496ms 达到三个峰值，不持续循环。
- 约 **2430ms** 在黑场下挂载档案页，最后约 448ms 打开快门，衔接卡片显现。
- `src/EntryTransition.jsx` 的 `ENTRY_DURATION` / `ENTRY_SWITCH` 控制时间；独立的 `entry-transition.css` 中 `projector-*` 关键帧控制画面。时长修改需保持两处时间关系一致。
- 首页视频在转场开始时暂停，离开页面后卸载；切换到后台也暂停。持续播放仅用于首页的动态短片，不用于其他视觉装饰。
- 系统减少动态设置仍使用 480ms 短黑场；播放途中开启该设置，会中止复杂画面并尽快进入档案。

## 替换视频、图片与文案

所有内容集中在 `photos.js`：

- `album.video` / `album.videoPoster`：首页视频与封面。支持 MP4 / WebM；设视频路径为空会显示封面图。
- `album.homeTitle` / `recallTitle` / `motto` / `note`：首页文案。
- `photos`：图片路径、标题、替代文字、裁切中心。`src: ''` 显示静态占位，相应日记照片不可点击。
- `volumes`：五组档案的封面、名称、开篇短文，以及每篇日记的照片、标题、分类和正文。

将自己的素材放进 `assets/photos/` 或 `assets/video/`，再改配置。保留唯一 ID；更换首页封面后同步修改 `index.html` 的 preload 路径。示例照片来自原仓库的 Unsplash 素材；首页新增雪山徒步示例短片，来源记录在 `assets/video/CREDITS.md`。四张上传截图作为交互和版式参考，截图中的播放器播放三角没有作为网页控件照搬。

## 页面地址

- `#home`：视频入口。
- `#archive`：胶片档案。
- `#daybook/woodlands`：林间日记，其他系列使用对应 volume ID。
- `#daybook/woodlands/photo/forest`：照片详情，支持直接访问和刷新。

## 文件与存储

- `src/App.jsx`：首页、档案、日记、详情及地址状态。
- `src/EntryTransition.jsx`：闪烁转场结构与时间常量。
- `entry-transition.css`：完全不依赖照片的图形转场样式。
- `src/useMotionPreference.js`：实时动态偏好订阅。
- `src/wheelIntent.js`：滚轮单位归一化及滑动意图识别。
- `src/useSmoothScroll.js`：日记页桌面滚轮缓动与中断处理。
- `styles.css`：四屏版式、响应式与胶片关键帧。
- `scripts/`：依赖安装、构建与开发监听。
- `DESIGN.md`：当前实现规范。`docs/PRD.md` 保留早期规划，以本次参考图方案为当前范围。
